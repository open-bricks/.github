# open-bricks GitHub Profile

This repository provides the public organization profile and community health defaults for [open-bricks](https://github.com/open-bricks).

## Files

| Path | Purpose |
|---|---|
| `profile/README.md` | Public organization landing page shown on `github.com/open-bricks` |
| `profile/open-bricks-banner.svg` | Banner used by the profile README |
| `profile/open-bricks-avatar.svg` | Avatar asset for the organization profile |
| `CONTRIBUTING.md` | Default contribution guidance for repositories without their own file |
| `CODE_OF_CONDUCT.md` | Default code of conduct |
| `SECURITY.md` | Default vulnerability reporting guidance |
| `PULL_REQUEST_TEMPLATE.md` | Default pull request checklist |
| `ISSUE_TEMPLATE/` | Default issue templates |
| `FUNDING.yml` | Funding links |
| `llms.txt` | Machine-readable ecosystem summary for LLM agents and crawlers |

## Scope

open-bricks is an umbrella profile for local-first desktop software, document tools, developer tools, AI infrastructure, research software, and public-interest prototypes across related organizations.

For product code, use the linked project repositories under `file-bricks`, `doc-bricks`, `dev-bricks`, `ellmos-ai`, `research-line`, `biotec-line`, `assistassets-ai`, `entertain-and-more`, and `um-bruch`.
